El conjunto de datos de cuidado de plantas de interior: 270 especies con métricas cuantitativas de luz (lux), riego y temperatura, vinculadas a la toxicidad para mascotas de la ASPCA y a una taxonomía verificada con GBIF.

Resumen

Igual que un pliego de herbario convierte una planta viva en un registro etiquetado, FloraDB convierte los consejos de cuidado imprecisos —"luz brillante indirecta", "regar cuando esté seca"— en bandas de lux e intervalos de riego legibles por máquina. Cada registro tiene una calificación de confianza, su toxicidad procede de la ASPCA o figura honestamente como desconocida, y su nombre enlaza con GBIF para que cualquier dato pueda volver a verificarse.

Lámina II · Cómo se construye cada registro

Tres capas
Capa i · Taxonomía
Nombres verificados con GBIF

Cada nombre se coteja con el GBIF Taxonomic Backbone: nombres aceptados canónicos, sinónimos conservados (Sansevieria → Dracaena) y un gbif_source_url para volver a verificar cada registro.

Capa ii · Seguridad
toxicidad para mascotas ASPCA

Determinaciones para perros y gatos con signos clínicos de ingestión. toxicity_status es aspca_verified, de forma conservadora genus_inferred, o unknown: nunca suponemos "segura".

Capa iii · Cuidados
Métricas normalizadas

Cada categoría de luz se corresponde con una banda de lux estándar; el riego, la temperatura y la humedad proceden de normas por tipo de planta. Un indicador care_confidence califica cada fila con honestidad.

Lámina V · Preguntas frecuentes

Base de conocimiento botánica y de seguridad para mascotas

Preguntas frecuentes sobre el conjunto de datos y la taxonomía

¿Qué es el conjunto de datos FloraDB de cuidado de plantas de interior y toxicidad para mascotas?

FloraDB es un conjunto de datos botánico de campo, curado, con más de 270 plantas de interior que combina parámetros cuantitativos de cuidado (umbrales de luz en lux, intervalos de riego en días, rangos de temperatura y humedad) con estados verificados de toxicidad para perros y gatos de la ASPCA, síntomas clínicos y citas taxonómicas de GBIF.

¿Cómo se cuantifican los requisitos de luz y riego en FloraDB?

En lugar de etiquetas subjetivas como "medium light" o "water when dry", FloraDB ofrece rangos cuantitativos exactos: requisitos mínimos y máximos de luz en lux (p. ej., de 1.500 a 5.000 lux para Monstera deliciosa) e intervalos de frecuencia de riego en días basados en perfiles climáticos de interior estándar.

¿Se verifican los estados de toxicidad para mascotas con datos clínicos veterinarios?

Sí. Cada planta se coteja con la base de datos de plantas tóxicas del ASPCA Animal Poison Control Center (aspca_verified), indicando si la planta es tóxica para perros (is_toxic_to_dogs) o gatos (is_toxic_to_cats), junto con síntomas clínicos de toxicidad concretos, como irritación oral o efectos de glucósidos cardíacos.

¿Qué formatos de base de datos y exportaciones incluye el snapshot de FloraDB?

El snapshot descargable de FloraDB incluye un archivo de base de datos SQLite relacional normalizada (.db) junto con exportaciones limpias en CSV y JSON (floradb_sample.csv), listas para importar directamente en Python pandas, R, pipelines SQL o aplicaciones web modernas.
