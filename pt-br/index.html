O conjunto de dados de cuidados com plantas de interior: 270 espécies com métricas quantitativas de luz (lux), rega e temperatura, vinculadas à toxicidade para pets da ASPCA e a uma taxonomia verificada pelo GBIF.

Resumo

Assim como uma exsicata de herbário transforma uma planta viva em um registro etiquetado, o FloraDB transforma conselhos de cuidado vagos — "luz indireta intensa", "regar quando secar" — em faixas de lux e intervalos de rega legíveis por máquina. Cada registro recebe uma nota de confiança, sua toxicidade vem da ASPCA ou aparece honestamente como desconhecida, e seu nome remete ao GBIF para que qualquer fato possa ser verificado novamente.

Prancha II · Como cada registro é construído

Três camadas
Camada i · Taxonomia
Nomes verificados pelo GBIF

Cada nome é associado ao GBIF Taxonomic Backbone: nomes aceitos canônicos, sinônimos preservados (Sansevieria → Dracaena) e um gbif_source_url para verificar novamente cada registro.

Camada ii · Segurança
toxicidade para pets ASPCA

Determinações para cães e gatos com sinais clínicos de ingestão. toxicity_status é aspca_verified, de forma conservadora genus_inferred, ou unknown — nunca presumimos "segura".

Camada iii · Cuidados
Métricas normalizadas

Cada categoria de luz corresponde a uma faixa de lux padrão; rega, temperatura e umidade vêm de normas por tipo de planta. Um indicador care_confidence classifica cada linha com honestidade.

Prancha V · Perguntas frequentes

Perguntas frequentes sobre o conjunto de dados e a taxonomia

O que é o conjunto de dados FloraDB de cuidados com plantas de interior e toxicidade para pets?

O FloraDB é um conjunto de dados botânico de campo, curado, com mais de 270 plantas de interior, que combina parâmetros quantitativos de cuidado (limites de luz em lux, intervalos de rega em dias, faixas de temperatura e umidade) com status verificados de toxicidade para cães e gatos da ASPCA, sintomas clínicos e citações taxonômicas do GBIF.

Como as necessidades de luz e rega são quantificadas no FloraDB?

Em vez de rótulos subjetivos como "medium light" ou "water when dry", o FloraDB fornece faixas quantitativas exatas: necessidades mínima e máxima de luz em lux (ex.: 1.500 a 5.000 lux para Monstera deliciosa) e intervalos de frequência de rega em dias com base em perfis climáticos internos padrão.

Os status de toxicidade para pets são verificados com dados clínicos veterinários?

Sim. Cada planta é cruzada com o banco de dados de plantas tóxicas do ASPCA Animal Poison Control Center (aspca_verified), indicando se a planta é tóxica para cães (is_toxic_to_dogs) ou gatos (is_toxic_to_cats), junto com sintomas clínicos específicos de toxicidade, como irritação oral ou efeitos de glicosídeos cardíacos.

Quais formatos de banco de dados e exportações estão incluídos no snapshot do FloraDB?

O snapshot do FloraDB para download inclui um arquivo de banco de dados SQLite relacional normalizado (.db) junto com exportações limpas em CSV e JSON (floradb_sample.csv), prontas para importação direta em Python pandas, R, pipelines SQL ou aplicações web modernas.
